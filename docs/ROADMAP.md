# ROADMAP — SAAIA RAG On-Prem (v2.7)

Ce fichier sert de **table des jalons** et d’index vers les docs détaillées.

## Jalons
- M0 : Repo + docs + conventions
- M1 : API retrieval + chat-store + contrats
- M2 : Observabilité + readiness
- M3 : Ingestion robuste
- M4 : Infra prod + runbook
- M5 : Client WinUI (MVVM + settings + sessions)
- M6 : LLM local intégré + streaming
- M7 : Agent “ChatGPT-like” (plan → multi-search → synthèse)
- M8 : Packaging (zéro config)

## Préfixes de commit
- `docs:` documentation
- `server:` backend API
- `client:` WinUI
- `infra:` docker/compose/scripts
- `test:` tests/outillage
- `release:` packaging

## Règle
Un commit = un jalon (ou une sous-tâche explicitement nommée).
